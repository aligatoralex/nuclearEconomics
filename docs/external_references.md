# External references — cross-validation candidates for Krok 7+

Not added as git submodules or `pyproject.toml` dependencies. Listed here
as candidates for Krok 7+ validation work (manually transcribed reference
test vectors, not a live import) — repo/tool identifiers as given, not
guessed URLs; verify the exact link before use.

- **tannhorn/ele-cost** — reference implementation of the IEA/NEA 2020
  "Projected Costs of Generating Electricity" LCOE methodology.
- **NREL/ATB-calc** — NREL Annual Technology Baseline calculator, Fixed
  Charge Rate approach to levelized cost.
- **whatisnuclear enrichment/SWU calculator** — reference calculator for
  uranium enrichment (SWU) cost modeling.
